# Kings of Watershallow

An original browser worker-placement game inspired by the structure of classic hidden-identity city-building games. It uses original names, factions, art, cards, and code.

## Secret identities

Each player receives a hidden identity at the start. Identities award bonus VP for different strategies, including completed commission types, constructed buildings, Orders played, mandatory duties, retained adventurers, or retained coins.

Your identity is visible in the left-hand **Your secret identity** panel, including its projected bonus. All identities are revealed in the final standings.

## Cards

- 60 generated commissions across five categories.
- Ongoing commissions can provide recurring resources or bonus VP.
- 60 Orders using 15 distinct effects.
- Six mandatory duties with different costs and rewards.
- 18 constructible buildings.

## Map

Constructed buildings appear directly on the main city map. The map expands as buildings are added and scales to remain visible.

## Playing

Assign an agent, resolve its action, optionally complete one commission, then end the turn. Harbour agents reassign after normal placement. The game lasts eight rounds.

## Development

Open `index.html` locally, or deploy the repository with GitHub Pages. The JavaScript performs syntax checks in CI.
